# Day 24 — `*args` and `**kwargs` Deep Dive

This folder covers flexible function arguments in Python, following Day 23 (hashing, hash tables, dictionaries, and sets).

## Learning path

1. Read **[Day 24 Detailed Notes](Day-24-Args-and-Kwargs-Deep-Dive.md)**.
2. Type and run each example yourself.
3. Predict the output before executing the five prediction questions.
4. Complete all five practice challenges.
5. Build the flexible report mini-project.
6. Review mistakes and tick off the completion checklist.

## Topics

- Positional vs keyword arguments
- `*args` and tuple packing
- `**kwargs` and dictionary packing
- Parameter order and keyword-only parameters
- Argument unpacking in function calls
- Forwarding arguments through wrappers
- Common errors and practical patterns

## Prerequisites

Comfort with functions, parameters, tuples, lists, and dictionaries is recommended.

## Suggested completion criteria

Day 24 is complete when you can explain packing vs unpacking in your own words, finish the exercises without copying, and demonstrate your mini-project working with different inputs.
