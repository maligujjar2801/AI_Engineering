## What I Learned

Today I learned about Python's special methods, also known as magic or dunder methods. I understood how Python automatically calls methods like `__str__()`, `__repr__()`, `__len__()`, and `__eq__()` during built-in operations. I also learned the basics of operator overloading, allowing custom objects to work with operators such as `+` and `==`. Finally, I learned the purpose of `NotImplemented` and when it should be returned inside magic methods for unsupported operations.
