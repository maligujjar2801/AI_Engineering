## 📖 What I Learned

Today I learned one of the four pillars of Object-Oriented Programming: **Inheritance**.

I learned how a child class can inherit the attributes and methods of a parent class, which helps avoid code duplication and makes programs more organized and reusable.

I also learned how the `super()` function works, why it is used to access the parent's constructor, how method overriding allows a child class to provide its own implementation of a parent's method, and how to check object and class relationships using `isinstance()` and `issubclass()`.

This chapter helped me understand how real-world OOP applications reuse code efficiently.
