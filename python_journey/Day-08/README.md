## 🎯 What I Learned

Today I learned the difference between class variables and instance variables and when to use each of them. I also learned how class methods work with the class itself using `cls`, while static methods are independent utility methods that don't require `self` or `cls`. I explored the `__str__()` magic method to customize object output and practiced object interaction (composition), where one object can use another object to perform a task. These concepts gave me a deeper understanding of how Object-Oriented Programming is used to build organized and reusable applications.

## 📌 Key Takeaways

- Class variables are shared by all objects.
- Instance variables are unique to each object.
- Class methods use `cls`.
- Static methods don't use `self` or `cls`.
- `__str__()` controls how an object is displayed when printed.
- Objects can work together through composition.
- OOP helps make code modular, reusable, and easier to maintain.
