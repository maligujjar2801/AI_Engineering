## What I Learned

Today I learned one of the four pillars of Object-Oriented Programming: **Polymorphism**. I understood that polymorphism allows the same method to behave differently depending on the object calling it. I also learned how method overriding helps achieve polymorphism through inheritance, how Python uses Duck Typing instead of strict type checking, and how the `super()` function allows child classes to reuse parent class functionality instead of rewriting it. Finally, I learned the advantages of writing flexible, reusable, and maintainable code using polymorphism.
