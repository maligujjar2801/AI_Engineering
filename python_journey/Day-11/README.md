## 📖 What I Learned

Today I learned another important pillar of Object-Oriented Programming: **Encapsulation**.

I learned how encapsulation helps protect an object's data by restricting direct access to it. I understood the difference between public, protected, and private attributes, and how Python uses **Name Mangling** for private attributes.

I also learned how getter methods provide controlled access to private data and how setter methods allow safe modification by validating user input. This concept helps make programs more secure, organized, and easier to maintain.
