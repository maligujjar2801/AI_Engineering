# Day 25 of Python — SQLite CRUD

This folder contains beginner examples of Python's built-in `sqlite3` module and the CRUD workflow for working with a local SQLite database.

## Files

- `CREATE.py` — create the `students` table.
- `INSERT.py` — insert a student record.
- `READ.py` — read and print student records.
- `UPDATE.py` — update a student's marks.
- `DELETE.py` — delete a student row by ID.
- `sqlite3_CURD.py` — combined create, insert, update, and read example (`CURD` is a typo for CRUD).
- `database.db` — SQLite database used by the examples.
- `notes.md` — concepts, file-by-file walkthrough, workflow, and improvement ideas.

Run the scripts from this folder so the relative path `database.db` resolves to this database. Start with `CREATE.py`, then try the individual CRUD scripts and inspect the results with `READ.py`.
