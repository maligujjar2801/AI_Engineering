## What I Learned

Today I built my first complete object-oriented Python application.

I learned how to:

- Design a class from project requirements.
- Store transactions using dictionaries inside lists.
- Use methods to organize code.
- Transfer money between objects.
- Format output exactly according to specifications.
- Generate text-based charts using nested loops.
- Handle challenging spacing and formatting requirements.

This was one of the most challenging projects I've completed so far because of the strict formatting requirements, but I solved it with my own implementation.
