## Learning Objectives

By completing this lesson, you should be able to:

- Distinguish a map, hash map, hash table, Python `dict`, Python `set`, and the `map()` function.
- Explain hashes, hash-table lookup, and collisions at a conceptual level.
- Use dictionary operations such as indexing, `.get()`, `.items()`, insertion, updating, and deletion.
- Understand hashability and the equality/hash contract.
- Use sets for uniqueness, membership checks, and union/intersection/difference operations.
- Build frequency counters, group records, detect duplicates, and work with nested dictionaries.
- Explain average-case O(1) lookup and why it is not an unconditional guarantee.
- Complete the Word Analyzer mini project and practice exercises.

## Topics Covered

1. Map vs hash map vs hash table vs `dict` and `set`
2. Hashing and the `hash()` function
3. Hash-table storage and collisions
4. Dictionary operations and iteration
5. Hashable objects and valid keys
6. The equality-and-hash contract
7. Set operations and `frozenset`
8. Dictionary and set comprehensions
9. Frequency counting, grouping, deduplication, and caching
10. Time complexity, common bugs, exercises, answer key, and a mini project
